\section{Verified anchors of the case study}
\label{app:anchors}

\S\ref{sec:bg-evidence}, with their exact signatures:

-- R3Cert.Step3.conjecture1_of_layers  (conditional capstone)
theorem conjecture1_of_layers (tieU : UTree)
    (Hnorm : forall t : UTree, exists s : List Hub,
        Balanced s /\ Capped s /\ Aobj t <= Aobj (backboneU s))
    (Hdom : forall s : List Hub, Balanced s -> Capped s ->

\section{Reproducing the verification}
\label{app:repro}

The verification results are produced by continuous integration and are reproducible
locally. In outline (see the repository workflows for exact, pinned commands; all
components are pinned to the same \Lean{} toolchain, \code{v4.32.0}):
\begin{enumerate}[nosep,leftmargin=1.4em]
  \item Build the formalization: \code{lake exe cache get} then \code{lake build}.
  \item Build the judge from the matching tag:
    \code{lake build lean4export comparator} in a checkout of \code{comparator@v4.32.0};
    build \nanoda{} with \code{cargo build --release}.
  \item Run each anchor: \code{lake env comparator <anchor>.comparator.json} from the
    project directory, with the exporter, \nanoda, and sandbox binaries on the path.
\end{enumerate}
A green run reports, per anchor, that both kernels accept the exported proof and that
its axiom set is within the whitelist.
