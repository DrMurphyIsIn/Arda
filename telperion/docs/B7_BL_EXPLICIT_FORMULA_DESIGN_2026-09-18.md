## 0. The statement (as registered)

Node `RH_bl_explicit_formula`, kind `milestone`, deps `RH_limit_explicit_formula`,
`RH_bl_finite_multiset`. Vocabulary in the AUTHORED block `BombieriLagarias` of
`missions/rh/lean/Statements/RHDefs.lean` (generated by `build_rhdefs.py`; the `RvMCount` and
`WeilExplicit` literals are untouched).

```lean
namespace BombieriLagarias

noncomputable def liKernel (n : ℕ) (ρ : ℂ) : ℂ := 1 - (1 - 1 / ρ) ^ n

noncomputable def liZeroSum (n : ℕ) (T : ℝ) : ℂ :=
  ∑ᶠ ρ ∈ {ρ : ℂ | 0 < ρ.re ∧ ρ.re < 1 ∧ |ρ.im| ≤ T},
    (WeilExplicit.zeroMult ρ : ℂ) * liKernel n ρ

noncomputable def archSide (n : ℕ) : ℂ :=
  1 - ((n : ℂ) / 2) * ((Real.eulerMascheroniConstant : ℂ) + (Real.log Real.pi : ℂ)
      + 2 * (Real.log 2 : ℂ))
    + ∑ j ∈ Finset.Icc 2 n,
        (-1 : ℂ) ^ j * (n.choose j : ℂ) * (1 - 1 / (2 : ℂ) ^ j) * riemannZeta (j : ℂ)

noncomputable def zetaLogDerivReg : ℂ → ℂ :=
  Function.update (fun s : ℂ => -logDeriv riemannZeta s - 1 / (s - 1)) 1
    (-(Real.eulerMascheroniConstant : ℂ))

noncomputable def eta (j : ℕ) : ℂ := iteratedDeriv j zetaLogDerivReg 1 / (j.factorial : ℂ)

noncomputable def finiteSide (n : ℕ) : ℂ :=
  -∑ j ∈ Finset.Icc 1 n, (n.choose j : ℂ) * eta (j - 1)

end BombieriLagarias

theorem bl_explicit_formula (n : ℕ) (hn : 0 < n) :
    Tendsto (BombieriLagarias.liZeroSum n) atTop
      (𝓝 (BombieriLagarias.archSide n + BombieriLagarias.finiteSide n)) := by sorry
```

In classical notation, for every `n ≥ 1`, with `m(ρ)` the multiplicity of `ρ` as a zero of `ζ`
in the open strip,

```
lim_{T→∞}  Σ_{|Im ρ| ≤ T} m(ρ) [1 − (1 − 1/ρ)^n]
   =  1 − (n/2)(γ + log π + 2 log 2) + Σ_{j=2}^{n} (−1)^j C(n,j) (1 − 2^{−j}) ζ(j)     [S_∞(n)]
      − Σ_{j=1}^{n} C(n,j) η_{j−1},      −ζ'/ζ(s) − 1/(s−1) = Σ_{j≥0} η_j (s−1)^j,  η_0 = −γ   [S_f(n)]
```

The left side is Li's `λ_n` (Li 1997, eq. (1.2), summed "in the symmetric order"); the right side is
Bombieri-Lagarias 1999, Theorem 2 (`S_∞(n) + S_f(n)`), re-derived in §3 and checked numerically to
`10^{−39}` in §5. The Laurent constants are written with the sign convention displayed above; it is
the convention under which `η_0 = −γ` and `S_f(n) = −Σ C(n,j) η_{j−1}`, and it agrees with the
regularized prime-sum representation `η_j = ((−1)^j / j!) lim_x [Σ_{k≤x} Λ(k)(log k)^j / k −
(log x)^{j+1}/(j+1)]` (checked numerically in §2.4; this representation is deliberately NOT part of
the statement).

## 1. The Bombieri-Lagarias test functions, exactly

### 1.1 Zero side

Li's criterion (Li 1997): with `λ_n := Σ_ρ [1 − (1 − 1/ρ)^n]`, RH holds iff `λ_n ≥ 0` for all
`n ≥ 1`. In the E8 coordinates (`ρ = 1/2 + iγ_ρ`, `H(ρ) = h(γ_ρ)`) the kernel is the rational
function

```
H_n(s) = 1 − (1 − 1/s)^n = Σ_{j=1}^{n} (−1)^{j+1} C(n,j) s^{−j},
h_n(r) = H_n(1/2 + ir) = n/(ir) − C(n,2)/(ir)² + …           (r → ±∞)
```

with a pole of order `n` at `s = 0` (i.e. `r = i/2`, the edge of the strip `|Im r| ≤ 1/2`) and a
simple zero at `s = ∞` (`H_n(s) ~ n/s`). On the line it decays only like `n/|r|`. Bombieri-Lagarias 1999, Theorem 1, is the multiset criterion: for a multiset `R` with
`0 ∉ R`, `Σ (1 + |Re ρ|)/(1 + |ρ|)² < ∞` and `R = 1 − R̄`, all `Re ρ ≤ 1/2` iff
`Σ_ρ Re [1 − (1 − 1/ρ)^{−n}] ≥ 0` for all `n ≥ 1`; its finite core is the registry's
`RH_bl_finite_multiset` (B7-i), written with the reflected kernel `1 − ((1 − 1/ρ)⁻¹)^n =
H_n(1 − ρ)`.

### 1.2 Prime side

Under E8's dictionary `H_g(s) = ∫ g(u) e^{(s−1/2)u} du`, the kernel `s^{−j}` (for `Re s > 0`) is
`(1/(j−1)!) ∫_0^∞ v^{j−1} e^{−sv} dv`, so `H_n = H_{g_n}` with

```
g_n(u) = e^{u/2} · P_n(u) · 1_{u<0},     P_n(u) = Σ_{j=1}^{n} C(n,j) u^{j−1}/(j−1)! = L^{(1)}_{n−1}(−u)
```

(`L^{(1)}_{n−1}` the associated Laguerre polynomial; Bombieri-Lagarias note the Laguerre form).
Three features, each a failure of a class hypothesis:

| feature | consequence | which class it violates |
|---|---|---|
| jump at `u = 0` (`g_n(0−) = P_n(0) = n`, `g_n(0+) = 0`) | `h_n(r) ~ n/(ir)`: the `1/|r|` decay IS the jump | E8 (`C^∞`), Guinand (`h = O(|r|^{−2−δ})`) |
| borderline decay `g_n(u) ~ |u|^{n−1} e^{−|u|/2}` as `u → −∞` | `g_n(−log k) = k^{−1/2} P_n(−log k)`, so the prime side `Σ_k Λ(k)/√k · g_n(−log k) = Σ_k Λ(k) P_n(−log k)/k` **diverges** (`Σ_{k≤x} Λ(k)(log k)^j/k ~ (log x)^{j+1}/(j+1)`); equivalently `H_n` has a pole at `s = 0`, on the boundary of Guinand's strip `|Im r| ≤ 1/2` | E8 (compact support), Guinand (`g = O(e^{−(1/2+δ)|u|})`) |
| E8's pole term `H_{g_n}(0) = ∫_{−∞}^0 P_n(u) du` | **infinite**; `H_n(1) = 1` is fine | — |

So `g_n` is in neither class, and the two divergences (pole term, prime side) are the same
divergence seen from the two ends of the strip. This is exactly the "admissibility gap" the
roadmap flags at B7-ii, made precise: no growth/regularity class extension of E8 with both sides
convergent *as written* contains `g_n`. The E8 theorem `RvMBridge4.limit_explicit_formula`
cannot be applied to `g_n`, and its `HasSum` conclusion would be false for `H_n` (§2.1).

## 2. The class extension, precisely

The honest answer is not a bigger growth class. It is: a **countable family** of rational kernels
(`H_n`, `n ≥ 1`), with the zero side summed in a **specific order** and the arithmetic side in
**regularized (residue) form**. Each decision below is forced.

### 2.1 Zero side: symmetric order is necessary and sufficient

*Necessity.* The family `ρ ↦ m(ρ) H_n(ρ)` is not summable in `ℂ`: `|H_n(ρ)| ~ n/|γ|` and
`Σ_{0<γ≤T} 1/γ ~ (log T)²/(4π)` (from `N(T) ~ (T/2π) log T`, `RH_rvm_unconditional`). In a
finite-dimensional space summability is absolute summability, so a `HasSum` statement (the E8
shape) would be **false**, not vacuous. One-sided windows `0 < Im ρ ≤ T` diverge: their imaginary
part is `~ −i n (log(T/2π))²/(4π)` (§5: `−1.565i` at `T = 542` for `n = 1`, predicted `−1.58i`).

*Sufficiency.* The window `W_T = {ρ : 0 < Re ρ < 1, |Im ρ| ≤ T}` is closed under `ρ ↦ ρ̄` and
`ρ ↦ 1 − ρ`, and `m(ρ̄) = m(1 − ρ) = m(ρ)` (conjugation; functional equation, both theorems
about the divisor of `ζ`). Hence

```
Σ_{W_T} m(ρ) H_n(ρ) = Σ_{W_T} m(ρ) H̃_n(ρ),    H̃_n(s) := ½ [H_n(s) + H_n(1−s)] = 1 − ½[((s−1)/s)^n + (s/(s−1))^n],
```

and `H̃_n(s) = O(n²/|s|²)` on the strip (the `n/s` and `n/(1−s)` leading terms cancel to
`n/(s(1−s))`). With `Σ_ρ m(ρ)/|ρ|² < ∞` (Zeta23 `WeilEF.zero_sum_inv_sq`, from the local count
`N(t, t+1] = O(log t)`) the symmetrized family is absolutely summable, so the window sums converge
to its `tsum`, and the limit is independent of the window family as long as it is pairing-closed.
The registered statement uses the symmetric windows and the *unsymmetrized* Li kernel, because
that is Li's `λ_n` and B7-i's sums; the symmetrized kernel is the proof device.

*The `O(log T)` count over ordered partial sums.* It is not needed for convergence (any
`N(T) = O(T^{2−δ})` gives `Σ 1/γ² < ∞`); it gives the **rate**: the tail of the paired sum past
height `T` is `Σ_{γ>T} O(n²/γ²) = O(n² log T / T)`. That effective truncation bound is the form the
B7-ii defect reading (a finite truncation's negative index counts the off-line pairs it sees;
Bombieri 2000, Alpöge-Furman §7.1) and B10's tail budget will consume; it is a follow-up node, not
this one (registry convention: O-form limits first, effective forms queued, as for E7/E8).

### 2.2 Archimedean side: closed form, not an integral

E8's archimedean side for a test function is `H(0) + H(1) − g(0) log π + (1/2π)∫ h(r) Re ψ(1/4+ir/2) dr`.
For `H_n` the pole term `H(0)` is infinite, `g_n(0)` is ambiguous (Fourier inversion at a jump gives
the midpoint `n/2`, which is indeed what the `−(n/2) log π` term says), and the integral converges
only as a principal value for `h_n` (its odd `n/(ir)` part against the even `Re ψ ~ log|r|`) and
absolutely for `h̃_n`. Rather than register three regularizations, the statement uses the
evaluated closed form `S_∞(n)` of Bombieri-Lagarias Theorem 2. §3 shows how each closed-form term
arises from the E8 terms (`ψ(1/2) = −γ − 2 log 2`, `ψ^{(k)}(1/2) = (−1)^{k+1} k! 2^{k+1}(1 − 2^{−(k+1)}) ζ(k+1)`),
so the explicit-formula lineage of every term is visible. `S_∞(n)` is the term B8 consumes
(Coffey/Lagarias: `S_∞(n) = (n/2) log n + O(n)`).

### 2.3 Arithmetic side: residues, not a prime comb

The naive prime side diverges (§1.2). What replaces it is the residue at `s = 1` of the rational
kernel against `Λ'/Λ`, which is a finite combination of the Laurent coefficients of `ζ'/ζ` at
`s = 1`: `S_f(n) = −Σ_{j=1}^n C(n,j) η_{j−1}`. The registry defines `η_j` **analytically**, as
Taylor coefficients at `1` of `−ζ'/ζ(s) − 1/(s−1)` extended by its limit `−γ`. This is the
Mathlib-provable object: `tendsto_riemannZeta_sub_one_div` (`ζ(s) − 1/(s−1) → γ`, proved by the
removable-singularity theorem, so the extension is analytic) gives `−ζ'/ζ − 1/(s−1) → −γ`.

### 2.4 The regularized prime-sum representation (deliberately excluded)

Bombieri-Lagarias also express `η_j` as regularized sums over prime powers,
`η_j = ((−1)^j/j!) lim_{x→∞} [Σ_{k≤x} Λ(k)(log k)^j/k − (log x)^{j+1}/(j+1)]`. Checked
numerically with a sieve to `x = 3·10⁶`: `A_0 = −0.577217` vs `η_0 = −0.577216`; `A_1 = −0.187568`
vs `−1!·η_1 = −0.187546`; `A_2 = −0.103669` vs `2!·η_2 = −0.103377` (the drift is the
`O((log x)^j · E(x)/x)`-type remainder). For `j = 0` this is Mertens (elementary); for `j ≥ 1` the
existence of the limit is **PNT with an error term** (`ψ(x) − x = O(x/(log x)^{j+1+δ})` suffices;
de la Vallée Poussin's does). That is a genuinely different theorem, hidden inside a
"prime comb" formulation. It is the diffraction reading of `S_f(n)` and belongs on the queue as its
own node (`RH_bl_eta_prime_sums`, statement: `∀ j, Tendsto (fun x => Σ_{k≤x} Λ(k)(log k)^j/k −
(log x)^{j+1}/(j+1)) atTop (𝓝 ((−1)^j j! η_j))`), with Zeta23's `FromPNTPlus/MediumPNT` as the
candidate input. It is not smuggled into this statement.

## 3. Derivation: the E8 contour with the rational kernel

This is the sense in which the node is "E8 on the BL class": the same rectangle contour, with two
changes forced by the kernel's poles. Let `Λ(s) = π^{−s/2} Γ(s/2) ζ(s)` (Mathlib
`completedRiemannZeta`), `Λ'/Λ(s) = −Λ'/Λ(1−s)`, simple poles at `0, 1`, zeros the nontrivial
zeros with multiplicity. Use the symmetrized kernel `H̃_n` of §2.1, `H̃_n(1−s) = H̃_n(s)`, poles of
order `n` at `s = 0` and `s = 1`, `H̃_n(s) = O(1/|s|²)`.

Integrate `H̃_n · Λ'/Λ` around `[−δ, 1+δ] × [−T', T']` at corridor heights `T'`
(`RH_corridor_bound`, both signs by conjugate symmetry):

1. **Residues.** Zeros: `Σ_{|Im ρ|≤T'} m(ρ) H̃_n(ρ)` (= the window sum of the Li kernel, §2.1).
   Poles: `Res_{s=1} H̃_n(s) Λ'/Λ(s) + Res_{s=0} H̃_n(s) Λ'/Λ(s)`, equal by the symmetry
   `s ↦ 1−s`, so `2 Res_{s=1} H̃_n Λ'/Λ = Res_{s=1} [H_n(s) + H_n(1−s)] Λ'/Λ(s)`. The `H_n(s)`
   half is regular at `1` (`H_n(1) = 1`) and contributes `−1` (the simple pole of `Λ'/Λ` with
   residue `−1`); the `H_n(1−s) = −Σ_{j=1}^n C(n,j)(s−1)^{−j}` half picks out the Laurent
   coefficients of `Λ'/Λ` at `1`.
2. **Horizontal edges → 0**: `|H̃_n| = O(1/T'²)`, `|Λ'/Λ| ≤ |ζ'/ζ| + |Γℝ'/Γℝ| = O(log² T')` on the
   corridor (`RvMBridge3.corridor_bound` + the Γℝ strip bound `norm_logDeriv_Gammaℝ_le_log_strip`).
3. **Right edge** `Re s = 1+δ`: `Λ'/Λ = −½ log π + ½ ψ(s/2) − Σ_k Λ(k) k^{−s}`. The prime part
   `∫_{(1+δ)} H̃_n(s) Σ_k Λ(k)k^{−s} ds` is **zero**: push the line to `Re s → +∞`
   (`Σ_k Λ(k)k^{−s} → 0` uniformly, `H̃_n = O(1/s²)`, no poles crossed). This is where the
   divergent prime comb disappears — it is never expanded term by term. The `log π` and `ψ` parts
   are the archimedean integrals, evaluated by shifting to `Re s = 1/2`; the shift crosses only the
   pole of `H̃_n` at `s = 1` (`ψ(s/2)` is regular there), whose residue is part of the Laurent
   bookkeeping of step 1.
4. **Left edge**: by the functional equation and `H̃_n(1−s) = H̃_n(s)` it equals the right edge.
5. **`T' → ∞`**: the window sums converge (absolute summability of the symmetrized family,
   Zeta23 `zero_sum_inv_sq`).

Collecting, `λ_n = Σ_{j=1}^n C(n,j) c_{j−1}` with `c_k` the Taylor coefficients of `ξ'/ξ` at `1`,
`ξ = ½ s(s−1) Λ`. Since `ξ'/ξ(s) = 1/s + 1/(s−1) − ½ log π + ½ ψ(s/2) + ζ'/ζ(s)`:
`1/s` contributes `Σ_{j=1}^n C(n,j)(−1)^{j−1} = 1`; `−½ log π` and `½ψ(1/2) = −γ/2 − log 2`
contribute `−(n/2)(log π + γ + 2 log 2)`; `½ψ(s/2)` at order `k ≥ 1` contributes
`(−1)^{k+1}(1 − 2^{−(k+1)}) ζ(k+1)`, i.e. `Σ_{j=2}^n (−1)^j C(n,j)(1 − 2^{−j}) ζ(j)`; and
`1/(s−1) + ζ'/ζ(s) = −(−ζ'/ζ − 1/(s−1))` contributes `−Σ_{j=1}^n C(n,j) η_{j−1}`. That is
`S_∞(n) + S_f(n)`.

The same coefficients `c_k` are what Li's generating function `d/dz log ξ(1/(1−z)) = Σ λ_n z^{n−1}`
produces (`λ_n = Σ_{j=1}^n C(n,j) c_{j−1}` by expanding `(1−z)^{−(k+2)}`), which is the corpus'
Taylor face `LiCriterion.taylorCoeff riemannXi (n−1)`. Bombieri-Lagarias prove Theorem 2 this way
(a Taylor computation at `s = 1`, no contour), taking `λ_n = Σ_ρ[…]` from Li 1997, who uses the
Hadamard product of `ξ`. The contour route above replaces the Hadamard product by the E8
machinery already on the island, which is why the node sits under E8 in the registry.

**Route not to take.** Approximating `g_n` by `C_c^∞` functions `g_{n,R,ε}` and applying the
literal E8 theorem forces one to track `H_{g_{n,R}}(0) ~ ∫_{−R}^0 P_n` against the prime sum
truncated at `k ≤ e^R`, both divergent like `R^n`; their difference converges to the `η`'s only
through the regularized prime-sum theorem of §2.4 (PNT strength). The contour route needs none of
it.

## 4. Consumers and the exact seams

### 4.1 B7-ii (the Bombieri-Lagarias analytic layer) and `RH_bl_finite_multiset`

The window sum `liZeroSum n T` is the finite Li-type sum of B7-i on
`S_T = {ρ : 0 < Re ρ < 1, |Im ρ| ≤ T, ζ(ρ) = 0}`: `0, 1 ∉ S_T` automatically, and `S_T` is closed
under `ρ ↦ 1 − ρ̄`. Two seams, both recorded in the node header:

* **Kernel form.** B7-i uses `1 − ((1 − 1/ρ)⁻¹)^n = H_n(1 − ρ)`; the node uses Li's `H_n(ρ)`.
  On a `1 − ρ`-closed set with `m(1−ρ) = m(ρ)` the two sums are equal *as complex numbers* (relabel
  `ρ ↦ 1 − ρ`); the relabeling lemma needs the functional-equation symmetry of `zeroMult`
  (`Zeta23.WeilEF.completedZeta_zeros_strip`, `Hfn_mirror` are the upstream shapes).
* **Multiplicity.** B7-i quantifies over a `Finset ℂ` (every point once); `liZeroSum` carries
  `zeroMult`. A multiple zero (none known, none excluded) would need B7-i's multiset form
  (BL's Theorem 1 is stated for multisets; the finite core's proof repeats points). Not fixed here.

With those two seams closed, B7-ii reads: "`λ_n = lim_T (B7-i's sum on S_T)`", and B7-i on each
`S_T` gives the truncation defect reading. The limit passage of BL Theorem 1 itself
(`Σ (1+|Re ρ|)/(1+|ρ|)² < ∞`, from `zero_sum_inv_sq`) is the remaining B7-ii content.

### 4.2 B10 / B8 / B1 / B2: the closed form and the companion identity

The right side is what B8 (archimedean trend) and B1 (arithmetic evaluation of `λ_n`) consume. To
connect with the pinned reduction `li_criterion_rh_iff` (RH ⟺ `∀ n, 0 ≤ Re (taylorCoeff riemannXi n)`),
a companion identity is needed, **statement only, not registered here** (it is a local Taylor
computation at `s = 1`, engineering; registering it is a decision for the lead):

```lean
theorem li_taylor_eq_bl (n : ℕ) (hn : 0 < n) :
    LiCriterion.taylorCoeff LiCriterion.riemannXi (n - 1)
      = BombieriLagarias.archSide n + BombieriLagarias.finiteSide n
```

(`taylorCoeff f n = (deriv^[n] (logDeriv (phi f))) 0 / n!`, `phi f z = f(1/(1−z))`, index shift:
rung `0` is `λ_1`.) At `n = 1` it reads `taylorCoeff riemannXi 0 = 1 + γ/2 − (log 4π)/2 =
1 + riemannZeta 1` in Mathlib's convention (`riemannZeta_one : riemannZeta 1 = (γ − log (4π))/2`,
`Mathlib/NumberTheory/Harmonic/ZetaAsymp.lean`), which turns `RH_li_rung0_kernel` (B2) into the
numeric inequality `2 + γ > log 4π` (`CONSUMER_SWEEP_2026-09-18.md` row 6). Probe 9 (§6) checks in
Lean that `archSide 1 + finiteSide 1` unfolds to exactly that closed form.

### 4.3 Route D

Nothing: the D-route consumes E8's `HasSum` form (`D6 = E7 + E8`) and band-limited/strip-analytic
classes, not Li's kernel.
