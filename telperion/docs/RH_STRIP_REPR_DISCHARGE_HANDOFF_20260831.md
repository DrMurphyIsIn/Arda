## R1 — the remaining work (the hard one)

Mathlib v4.32.0 has **no** fractional-part representation of `riemannZeta` (confirmed by reading
`RiemannZeta.lean`). R1 is a hand-rolled step of the analytic continuation:

    riemannZeta s = s/(s-1) - s·∫_{x>1} {x} x^{-(s+1)} dx     (Re s > 1).

Route (pinned): `tendsto_sum_mul_atTop_nhds_one_sub_integral₀` (in `Mathlib.NumberTheory.AbelSummation`),
`f x = x^{-s}`, `c 0 = 0`, `c (n≥1) = 1`. Gives `∑_{k≤n} k^{-s} → s∫_{t>1} ⌊t⌋ t^{-s-1} dt`; then
`⌊t⌋ = t - {t}` and `s∫_{t>1} t^{-s} dt = s/(s-1)` yield `stripRHS s`.
