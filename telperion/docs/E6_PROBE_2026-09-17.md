## Part B — Second bridge (`RH_rvm_unconditional`): NOT delivered, and why

Target (PR #545, `telperion/missions/rh/lean/Statements/RH_rvm_unconditional.lean` on
`feat/critical-path-nodes`):

with `zetaZeroCount T := ∑ᶠ ρ ∈ {ρ | 0 < ρ.re ∧ ρ.re < 1 ∧ 0 < ρ.im ∧ ρ.im ≤ T},
((MeromorphicOn.divisor riemannZeta {s | 0 < s.re ∧ s.re < 1} : ℂ → ℤ) ρ).toNat`.

**Finding: zeta-23-lean has NO cumulative Riemann–von Mangoldt theorem, and no stated form from
which the cumulative `O(log T)` remainder follows by assembly.** Precisely:

1. The only stated RvM results are the dyadic main clause
   `Zeta23.riemannVonMangoldt_zeta.main : ∃ C T₀, ∀ T ≥ T₀, |Ncount T (2T) − T/(2π)·ℓ₁(T)| ≤ C log T`
   (`Zeta23/Hypotheses.lean:67-70`, `Zeta23/RvM/MainTerm.lean:482-484`) and the local count
   `Ncount t (t+1) ≤ A₀ log(|t|+3)` (`Zeta23/RvM/LocalCount.lean:266-268`). There is no
   `Ncount 0 T` asymptotic anywhere (grep for `riemannVonMangoldt_cumulative`, `Ncount 0`,
   `tendsto ... Ncount`: only `XiPrime/Final.lean:257 tendsto_Ncount_atTop`, a dyadic divergence).
2. Summing the dyadic clause over `T, T/2, T/4, …` gives `N(0,T) = M(T) + O(log² T)`, NOT
   `O(log T)` (`Σ_k C log(T/2^k) ≍ C log² T`). So the target is **not** a corollary of the stated
   theorems.
3. The internal machinery is general-window: `N_eq_halfContour_completedZeta {T₁ T₂} (1 ≤ T₁ < T₂,
   good heights)` (`RvM/MainTerm.lean:46-49`), `halfContour_completedZeta_split` (`:82`),
   `gamma_side {T₁ T₂}` (`RvM/GammaSide.lean:121-122`, `(1/π) Im halfContour(logDeriv Γℝ) = ∫_{T₁}^{T₂} μ`),
   `backlund_horizontal_at` (`RvM/Backlund.lean:338-343`, at any good height `T ≥ 4`),
   `vertical_two` (`:400`), `exists_goodHeight` (`MainTerm.lean:196`), Stirling for `μ`
   (`GammaFacts/StirlingVert.lean:616`). From these an `O(log T)` cumulative formula IS
   derivable — fix `T₁` a good height in `[4,5]`, take `T₂` a good height in `[T, T+1]`, integrate
   Stirling over `[T₁, T₂]` (the dyadic `int_mu_of_stirling` at `GammaFacts/IntMu.lean:85` does
   not cover this; a new FTC lemma for `∫ (1/2π) log(τ/2π)` on a general interval and an
   `∫ C/τ²` tail bound are needed), then correct by two local counts — but that is **new proof
   work of a few hundred lines**, not definition-level assembly, and it was not attempted.
4. Multiplicity reconciliation is the easy half and is recorded here for whoever does 3: Zeta23
   uses `zeroMult ρ := (analyticOrderAt riemannZeta ρ).toNat` over `zerosIn 0 T` (zeros only);
   the registry uses `(MeromorphicOn.divisor riemannZeta U ρ).toNat` over the whole rectangle.
   Mathlib (51e6992e) `AnalyticOnNhd.divisor_apply : divisor f U z = ((analyticOrderAt f z).map (↑)).untop₀`
   (`Mathlib/Analysis/Meromorphic/Divisor.lean:72`) plus `Zeta23.RvM.analyticOnNhd_riemannZeta
   (1 ∉ S)` (`RvM/ZetaGrowth.lean:43`) give pointwise equality of the two multiplicities on the
   open strip; the divisor vanishes off zeros, so the two finsums agree
   (`finsum_mem_inter_support`-style rewriting). The constant `7/8` and the `T ≥ 2` range are
   absorbed by `C` (finite count on `[2, T₀]`, `log T ≥ log 2 > 0`).

So: the second bridge is feasible as a follow-up (estimate: one focused session), but per the
instruction it was not faked and is not in this PR.

## Part C — Roadmap correction

"Classically this follows from Riemann–von Mangoldt" is true only for a multiplicity-free window
count. In Lean terms the discharge input for `MM_rvm_unbounded_mean_density` is **Theorem A**
(a positive proportion of DISTINCT zeros on the critical line), not the RvM formula: any
multiplicity-weighted count bounds the fibre of `Complex.im` over an ordinate only by the local
count `O(log T)`, which reduces `T log T` to linear growth and gives bounded mean density.
Hardy–Littlewood's linear `≥ cT` is likewise insufficient. The primary candidate's own RvM theorem
(`exists_abs_riemannZeroCount_sub_mainTerm_le_log`, multiplicity-weighted) therefore could not
have discharged the node on its own; its native Selberg theorem could, but is unverified here.

## 5. Statement-match assessment and the bridge

In-tree target (`telperion/missions/mirrormere/lean/Statements/MMDefs.lean:48-53`, `MM_rvm_unbounded_mean_density.lean:10`):
```lean
def RvMUnboundedMeanDensity (S : Set ℝ) : Prop :=
  ∀ r : ℝ, 0 < r → ∃ (F : Finset ℝ) (a L : ℝ),
    0 ≤ L ∧ (↑F ⊆ S) ∧ (∀ x ∈ F, x ∈ Set.Icc a (a + L)) ∧ r * L + 1 < F.card
def zetaOrdinates : Set ℝ :=
  {t : ℝ | ∃ ρ : ℂ, riemannZeta ρ = 0 ∧ 0 < ρ.re ∧ ρ.re < 1 ∧ ρ.im = t}
theorem rvm_unbounded_mean_density : RvMUnboundedMeanDensity zetaOrdinates := by sorry
```

|---|---|---|---|
| (a) Mathlib `riemannZeta`, not a custom zeta | yes | yes | yes |

| (d) distinct ordinates | **NO — with multiplicity, and not convertible** (see below) | yes: distinct points on `Re = 1/2` have distinct `im` | yes: `N₀*` is an `ncard` of distinct points on `Re = 1/2` |
| trust | CI-asserted only | CI-asserted only, 216-module closure | Comparator-checked, `AUDIT.md`, plus this probe's build |

Why (d) fails for a multiplicity count: the map `im : zerosIn T (2T) → ℝ` can collapse several distinct zeros (e.g. `ρ` and `1 − conj ρ` when `Re ρ ≠ 1/2`) onto one ordinate, and the only available fibre bound is the local count `N(t, t+1] ≤ A₀ log(|t|+3)`, which turns `T log T` into `≍ T`, i.e. bounded mean density. Distinctness must come from the critical line (or from Theorem C's `Ndist` plus a fibre argument, which is worse). Hardy–Littlewood's linear `≥ cT` bound is also insufficient. So the roadmap's "classically this follows from RvM" is only true for the multiplicity-free window count; in Lean terms the needed input is a positive-proportion critical-line theorem.

Bridge lemma, as compiled in `E6Bridge.lean` (a `v4.33.0-rc2` file importing `Zeta23.Unconditional`, with the in-tree `MMDefs` vocabulary copied verbatim):
1. From `Zeta23.riemannVonMangoldt_zeta.main` obtain `C T₀` and, using `Zeta23.ell1_tendsto_atTop` (`PrimeSideB.lean:157`) and `Real.log`-vs-`T` growth, a `T₁` with `(T/(4π))·Real.log T ≤ Ncount T (2T)` for `T ≥ T₁` (elementary; ~30 lines).
2. From `Zeta23.thmA₀ (1/3)` get `T₂` with `(1/3)·Ncount T (2T) ≤ N0star T (2T)` for `T ≥ T₂`.
3. Let `S := zerosIn T (2T) ∩ {ρ | ρ.re = 1/2}`; `S.Finite` from `Zeta23.zetaSeam.finite_window`; `Set.InjOn Complex.im S` since `Re` is constant (`Complex.ext`); hence `(Complex.im '' S).ncard = S.ncard = N0star T (2T)` (`Set.ncard_image_of_injOn`).
4. `F := (hfin.image _).toFinset`, `a := T`, `L := T`. Then `↑F ⊆ zetaOrdinates` (unfold), `∀ x ∈ F, x ∈ Icc T (2T)` (from `T < ρ.im ≤ 2T`), and `r·T + 1 < F.card` once `(T/(12π))·log T > r·T + 1`, i.e. for `T` beyond `max T₁ T₂ (exp (12π(r+1)) + 1)` (~20 lines of `nlinarith`/`Real.add_one_le_exp` bookkeeping).
