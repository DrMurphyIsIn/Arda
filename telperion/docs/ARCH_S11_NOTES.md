## 2. How (bypass B4)

1. **Kernel.**  On [0, a], k(x, y) = pv E(\|x/a − y/a\|) + c0, with E_i = round(chiCo_i aⁱ, 24 digits)
   for i < 46.  `abs_chiPoly_sub_pv` gives \|chiPoly − pv E\| ≤ dR, which includes the dropped
   degrees 46..66 (dR = 1.0e-17 at a = 1/2, 5.5e-11 at a ≈ log 2).  `abs_re_inner_sub_le` adds
   (δ + dR)·a to every form bound.
2. **Exact central formula** (`ArchS11_Poly`).  For s ∈ [0, 1],
   ∫₀¹ \|s − t\|ⁱ tᵐ dt = Σ_d Fc(i, m, d) sᵈ.  This is a binomial expansion on [0, s] and [s, 1],
   with Pascal's triangle checked by recurrence.
   * The tables Ψ_m = T̂(tᵐ) (m < 8) are computed once per scale and checked by the kernel.
   * U_j = T̂Φ_j for the shifted Legendre polynomials Φ_j, j < 8, are lists checked against Ψ.
3. **Galerkin + Schur** (`ArchS11_Galerkin.galerkin_form`, abstract Hilbert space).
   * Write f = h + r with h the orthogonal projection on V = span Φ.
   * The cross term ⟪Th, r⟫ = ⟪Σ a_j ρ_j, r⟫ uses the exact residuals ρ_j = U_j − Σ B_jl Φ_l.
   * The residuals are bounded diagonally by weighted Cauchy–Schwarz (Sedrakyan) with weights ‖ρ_j‖^{1/2}.
     This costs at most 3e-5 in λ, against 0 for the full Gram matrix, and needs 8 moments instead of 64.
4. **Tail** (`norm_sq_ker_sub_tail`, `inner_tail_eq_zero`).
   * The one-sided kernel p(x, y) = Σ_j (2j+1) Φ_j(x/a) U_j(y/a) is invisible on V^⊥.
   * ‖k − p‖_{L²} is computed exactly (Fubini in both orders, KKh closed form) and bounded by q = a·q̂.
   * q only enters at first order, through q + 1/t ≤ λ.  Here q̂ ≈ 0.13 to 0.19 at N = 8.
5. **LDLᵀ** of λG − C − t·diag(dh), given as exact data and checked by the kernel.
6. **Interval transfer** (`extL`).  Extension by zero from [0, b] to [0, c] preserves norms,
   ⟪1, ·⟫ and kernel forms.
   * Upper bounds are certified on [0, H], with H = 0.6931471808 ≥ log 2 (`Real.log_two_lt_d9`).
   * The lower bound uses a test vector on [0, lo], with lo = 0.6931471803 ≤ log 2.
   * The γ-shift is the constant kernel c0 = −γ′/H (`inner_kerLp_const`), and γ′/H ≤ γ′/log 2.
7. **Derived statements.**  λ₂ comes from `minmaxEig_le` with U = span{1}, using the γ′ = 1 form.
   The overlap comes from the γ′ = 0.02 form evaluated at S5's top eigenvector.

## 4. Open items

1. **Translation.**  The theorems are on I = [0, |I|].  S12 needs the intervals [α, α + ℓ] (S8 `prop55`) or [−L, L].
   * Kernel forms are translation-invariant.
   * A transfer Lp(volI α (α+ℓ)) ≅ Lp(volI 0 ℓ), or a function-level corollary for continuous h with
     tsupport ⊆ [α, α+ℓ], is not done.
2. **Lp vs functions.**  S8's `prop55_lift` is a function-level double integral over ℝ².
   * Passing to ⟪K_I f, f⟫ for f = (h restricted to I) needs `inner_intOp_eq_integral` plus support bookkeeping.
   * This is S12's glue and is not done here.
3. **Courant–Fischer identification** (S5 open item 1) is not needed.
   * `minmaxEig K 2` is S5's variational λ₂.
   * The overlap statement uses the true top eigenvector from `exists_eigenvector_topEig_intOp`.
4. **Wiring.**  `defaultTargets` and `AxiomGuardRvMBridge.lean` are untouched.
   The 13 `[[lean_lib]]` stanzas are at the end of `lakefile.toml`.

## 5. Lean footguns met

* **`decide +kernel` "did not reduce" on large checks.**  This was the kernel heartbeat limit, not a wrong certificate.
  Put `set_option maxHeartbeats 0` in the Cert files.
* **Cost of exact moments.**  A 2,900-term exact `mom` of long degree-53 polynomials costs about 4 s of kernel
  time and much memory: 64 of them per certificate reached 27 GB RSS.  Keep big-polynomial moments to O(N) per certificate.
* **Never use `Nat.choose` inside kernel-evaluated code.**  The Pascal recursion is exponential.
  Use a literal table checked by its recurrence (`binOK`).
* **`intervalIntegral.integral_finsetSum` / `integral_add` rewrites fail on Pi-form integrands**
  (`(f * g) x`) produced by continuity terms.  Pass `(f := fun …)` explicitly.
* **Ambiguity under `open intervalIntegral`.**  `integral_const_mul` and `integral_ofReal` become ambiguous.
  Do not open `intervalIntegral` in files that use Bochner integrals.
* **`RCLike.continuous_ofReal.comp hF` gets stuck** in a statement.  Use a helper with 𝕜 fixed by its type (`continuous_ofReal_comp`).
* **`Set.mem_prod` with `simp`.**  Plain `simp` turns `Icc ×ˢ Icc` into `Icc (0,0) (b,b)`.  Use `simp only` with `Set.mem_prod`.

## 6. S11-lite (2026-10-11): bounded memory for CI

The GitHub runner has 16 GB and builds 4 modules in parallel.  The original certificate modules peaked at
11 to 15.5 GB each.  Each `ok*` checker was one `decide +kernel` performing 16 exact moments of long
polynomials, and the kernel caches grow with the number of operations in one declaration.

**What changed.**  No theorem statement, and no theorem or module name used downstream, changed.
`final_facts`, `KI_*`, `chiK*` and `ok*_ok` are all the same, and S12 builds unchanged.
* `ArchS11_Data` now defines per-row checkers (`psiRow`, `uRow`, `rhoRow`, `dRow`, `qRow`).
  `psiOK`, `uOK`, ... are `List.all` of these rows.  It also stores the exact tail moments `uu*`.
* Each row is its own `decide +kernel` theorem.  The rows live in 37 generated part modules:
  `ArchS11_CPsi{A,H,L}{0..3}`, and `ArchS11_C{T1,Top,Gam,Lam2,Ovl}_{U,R,D,UU,Q}`.
* `ArchS11_Split` holds the assembly lemmas: `rows8`, `uOK_of`, ..., `and6`, and `q2val_eq`.
  `q2val_eq` rewrites the tail through the diagonal moments, using the kernel-checked orthogonality of the Legendre basis.
* `ArchS11_CertPsi`, `ArchS11_CertT1`, `_T2a` and `_T2b` are now cheap assemblies that keep the old theorem names.
* The rounded data uses 16 significant digits instead of 24 to 30 (E, B, test vectors).
  All certified values are unchanged at the printed precision, and all margins hold.
  The data file went from 462 KB to 369 KB.
* `chico.py` keys its cache on the SHA-256 of `ArchS10_Data.lean`.  If S10 is regenerated (for example by S9-lite),
  rerun `gen_s11.py`.  The kernel check `roundOK` fails loudly on stale data.
