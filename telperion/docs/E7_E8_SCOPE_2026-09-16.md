## 1. E7 — the corridor bound

### 1.1 The classical statement (effective form)

For `s = σ + iT` with (say) `−1 ≤ σ ≤ 2` and `|T|` large, *provided `s` is at
distance `≥ δ` from every nontrivial zero within height 1 of `T`*,

>  `|ζ′/ζ(s)| ≤ (C_pf + C_count/δ)·(log T)²`.

Classical references: Titchmarsh, *The Theory of the Riemann Zeta-Function* (2nd
ed., Heath-Brown), §9.6(B) (the "on the corridors between zeros" estimate);
Iwaniec–Kowalski, *Analytic Number Theory*, Thm 5.17. Montgomery–Vaughan
*MNT* §12.1 gives the same estimate. (These page citations are from standard
analytic-NT and were NOT re-fetched this session — flagged for the auditor.)

### 1.2 The proof template (Titchmarsh §9.6)

Three bricks, in the corpus's own vocabulary:

1. **Partial-fractions / Hadamard representation.**
   `ζ′/ζ(s) = Σ_ρ 1/(s−ρ) + E(s)` where the sum runs over the zeros ρ within
   height 1 of `T` and `E(s) = O(log T)` collects the far zeros + the
   archimedean (Γ′/Γ) + pole terms. **This object already exists in-corpus**:
   `AllZerosUpToHeight.lean:95` / `AllZeros_h100.lean:188` state exactly
   `logDeriv riemannZeta z = (∑ ρ ∈ s, (d ρ : ℂ)/(z − ρ)) + E z`, with
   `d = MeromorphicOn.divisor riemannZeta (ball c R)` the multiplicity and `s`
   the local zero-finset. This is the realized Hadamard sum. It is the *same*
   representation the argument-principle box machinery
   (`RvMDiffractionCore.zeta_total_argChange_eq_count`,
   `bd_logDeriv_zeta_eq_count`) already consumes on the box edges.

2. **Local zero count (THE RvM GATE).** The number of zeros with
   `|Im ρ − T| ≤ 1` is `N(T+1) − N(T) = O(log T)`. This is the
   Riemann–von Mangoldt density input. **It is UNPROVED unconditionally
   in-corpus** — the `RvMUnboundedMeanDensity` residual (mirrormere
   `MM_rvm_unbounded_mean_density`, still `open`; survey 2026-09-15 found no
   unconditional proof anywhere). This is the entire gate.

3. **Zero-avoidance (corridor).** On an edge kept at distance `δ` from all
   nearby zeros, each `|1/(s−ρ)| ≤ 1/δ`, so `|Σ_ρ 1/(s−ρ)| ≤ (count)/δ ≤
   O(log T)/δ`. Together with brick 1's `O(log T)` error term this gives
   `O(log T) + O(log T)/δ`, and since `log T ≤ (log T)²` for `T ≥ 3` the clean
   `O(log²T)` follows. (The second power of log is the honest classical shape:
   one log from the count, absorbed into log² via the effective-constant packaging;
   Titchmarsh's `log²T` comes from allowing `δ ~ 1/log T`, the generic corridor width.)

### 1.3 The authored statement (registry node)

`missions/rh/nodes/RH_corridor_bound_effective.toml` +
`.../lean/Statements/RH_corridor_bound_effective.lean`, kind `lemma`, status
`draft` (awaiting independent blind read-back → `open`). Theorem
`corridor_logDeriv_bound_effective`. Design choices, all forced by the honesty
invariant and the corpus precedent:

- **Effective constant, not `O(·)`**: conclusion is a literal
  `‖ζ′/ζ‖ ≤ (Cpf + Ccount/δ)·(log T)²`, matching `RH_dlvp_region_effective`
  (explicit `dlvpRateC`) and `RH_backlund_s_log` (explicit
  `log((4T+19)/‖F_T 2‖)/log(7/6) + 2`) rather than a bare growth order.
- **RvM quarantined into `hlocalcount`**: `(Znear.card : ℝ) ≤ Ccount·log T`.
  This is the precedent used by `RH_backlund_s_log` (carries `hζne`) and
  `RH_dlvp_region_effective` (carries the disk-multiplicity divisor datum): the
  unproven analytic input is a NAMED HYPOTHESIS, so the node claims exactly the
  reduction and nothing more.
- **Partial fractions as `hpf`**: `‖ζ′/ζ(s) − Σ_{ρ∈Znear} 1/(s−ρ)‖ ≤ Cpf·log T`
  — the corpus's realized Hadamard form, with the `O(log T)` error term abstracted.
- **Corridor as `hgap`**: `δ ≤ ‖s − ρ‖` for every `ρ ∈ Znear`.
- `logDeriv riemannZeta` is exactly `ζ′/ζ` (Mathlib `logDeriv`); norm `‖·‖`
  per the island API (Backlund handoff: `Complex.abs` is removed).

**Sound-by-construction check** (a scoping author must not author a false
statement): from `hpf`, `‖ζ′/ζ‖ ≤ ‖Σ 1/(s−ρ)‖ + Cpf·log T`; each summand
`≤ 1/δ` by `hgap`, so `‖Σ‖ ≤ card/δ ≤ Ccount·log T/δ` by `hlocalcount`; and
`log T ≤ (log T)²` since `T ≥ 3 ⇒ log T ≥ log 3 > 1`. Hence the conclusion is a
genuine theorem of its hypotheses. The ONLY unprovable-today hypothesis is
`hlocalcount` (= RvM). This is what "gated" means precisely: everything except
`hlocalcount` is elementary; `hpf` is corpus-realized modulo the far-zero/arch
error bound; `hlocalcount` is the wall.

## 3. E8 — unconditional Guinand–Weil at all heights (diffraction form)

### 3.1 The statement (authored here; NOT a Lean node — see §3.4)

E8 is the `T → ∞` limit of the finite explicit formula
`rect_explicit_formula_bragg` (registry `MM_bragg_bridge`, W3b, kernel-proved),
upgraded to the full symmetric Guinand–Weil identity. In words:

> For an admissible test function `g` (test-class TBD, §3.3), the sum of `ĝ` over
> the nontrivial zeros ρ, taken **symmetrically** (ρ paired with `1−ρ`, i.e.
> `lim_{T→∞} Σ_{|Im ρ|≤T}`), equals the **diffraction / prime side**
> — `Σ_p Σ_{m≥1} (log p) p^{−m/2} (g(m log p) + g(−m log p))` — minus the
> archimedean term `(1/2π) ∫ g̃(r) (Γ′/Γ)(1/4 + ir/2) dr` plus the pole terms
> `ĝ(i/2) + ĝ(−i/2)`. In the corpus's diffraction coordinates: the finite
> `braggTerm` sum converges to the prime side, the finite box zero-sum
> `Σ_{ρ∈zeroFinset} d(ρ)·(…)` converges to the symmetric zero side, and the
> horizontal-edge integrals `∫ logDeriv ζ` vanish/converge under E7's corridor
> bound.

This is exactly `MM_bragg_bridge` (§below) with the box `[σ₀,σ₁]×[T₀,T₁]` sent to
the full critical strip and `T₁ → ∞`.

The finite anchor, `rect_explicit_formula_bragg`
(`MM_bragg_bridge.lean`, PROVED, diffraction form):
```
2πi·Σ_{ρ∈zeroFinset c R} d(ρ)
  = ∫_{σ₀}^{σ₁} ζ′/ζ(x+iT₀) dx − ∫_{σ₀}^{σ₁} ζ′/ζ(x+iT₁) dx
    − i·Σ'_n braggTerm σ₁ T₀ T₁ n − i·∫_{T₀}^{T₁} ζ′/ζ(σ₀+iy) dy
```
E8 = its limit: `T₁→∞`, `σ₀→0⁻`/`σ₁→∞` (or `σ₀=½−a, σ₁=½+a` with `a` fixed and
a test-function convolution replacing the sharp box), with:

- **the two horizontal edge integrals** `∫ ζ′/ζ(x+iT)` controlled by **E7** (the
  corridor bound is exactly the pointwise integrand estimate that makes the edge
  contribution `→ 0` / converge along a corridor sequence `T = T_k`);
- **the `braggTerm` tsum** converging to the full prime/diffraction side;
- **the box zero-sum** converging to the symmetric zero side (this is the
  conditional-convergence / functional-equation-pairing bookkeeping: off the line
  zeros come in FE quadruples `(ρ,1−ρ,ρ̄,1−ρ̄)`, and the sum converges only when
  paired — roadmap §2 "quadruple caveat").

### 3.3 Mathlib / formulation gaps (why E8 is hard-known-shape, not engineering)

The skeptic pass reclassified E8 from engineering to hard-known-shape (roadmap §8)
for reasons that are real formulation gaps, not just labor:

1. **Test class is undetermined.** "Admissible `g`" is not free: the naive
   `{±m log p}` comb is **unconditionally NOT tempered** (roadmap §1 correction:
   `Σ_{n≤e^R} Λ(n) n^{−1/2} ~ 2e^{R/2}`), and any band-limited compactly-supported
   class **cannot see off-line zeros** (Paley–Wiener, roadmap D3 refutation: the
   transform must be analytic in `|Im| ≤ ½`). So the honest E8 needs the
   *strip-analytic admissible class* — which is itself queued formulation work
   (roadmap §9 standing queue: "B6 test class", "D3 strip-analytic class"). The
   statement's meaning changes with the class; authoring a Lean theorem before the
   class is pinned would pin the wrong thing.
2. **Archimedean term.** The Weil form's `(Γ′/Γ)` term is NOT free in the corpus
   Bragg bridge (roadmap D2 correction: the bridge is stated for uncompleted ζ
   with edge remainders; the digamma term must be added from the `RvMArch`
   machinery — `RvMArchGrowthBounds`, `RvMDigammaLogDeriv` exist but aren't wired
   into a Weil-form statement).
3. **Conditional convergence.** Mathlib has `Tendsto`/`tsum` but no packaged
   "symmetric limit over FE-paired zeros" combinator; the pairing bookkeeping is
   bespoke.
4. **`braggTerm` tsum → prime side.** The corpus `braggTerm` is defined per-box;
   its `T→∞` limit to the classical `Σ_p Σ_m (log p)p^{−m/2}…` needs a
   convergence lemma that does not exist.

## 4. The tractable, RvM-INDEPENDENT partial lemma

The one genuinely non-gated piece peeled off E7: the **inequality-assembly
skeleton** — corridor bound *from* partial fractions + local count + gap, with
the count and the representation as hypotheses. This is pure `ℝ`/`ℂ` inequality
algebra; it touches neither RvM nor ζ-specific analysis. It is the *body* of
`corridor_logDeriv_bound_effective` above, and it is provable today:

```
Given  ‖X − S‖ ≤ Cpf·L   (hpf, X = ζ′/ζ(s), S = Σ 1/(s−ρ), L = log T ≥ 1),
       ‖s − ρ‖ ≥ δ > 0 for ρ ∈ Znear (hgap),
       card(Znear) ≤ Ccount·L (hlocalcount):
  ‖S‖ ≤ Σ ‖1/(s−ρ)‖ = Σ 1/‖s−ρ‖ ≤ card·(1/δ) ≤ (Ccount/δ)·L,   [triangle + hgap + hlocalcount]
  ‖X‖ ≤ ‖S‖ + ‖X−S‖ ≤ (Ccount/δ)·L + Cpf·L = (Cpf + Ccount/δ)·L,  [triangle + hpf]
       ≤ (Cpf + Ccount/δ)·L²                                       [L ≥ 1 ⇒ L ≤ L²].
```

**Status: NOT proved in-kernel this session** (no warm Lean cache in the worktree;
a full Mathlib v4.34 build is not resource-justified for a scoping task). It is
authored as the `:= by sorry` body of the registered `draft` node. The proof is
`Finset.sum` triangle inequality (`norm_sum_le`) + `one_div`/`norm_inv` +
`Finset.sum_le_card_nsmul` (or `Finset.card_nsmul_le_sum` variant) + `nlinarith`
on `L ≥ log 3 > 1`. Estimated: **hours** in a warm island, no new Mathlib.
Clearly RvM-independent — RvM enters ONLY through the *truth* of `hlocalcount`,
never its *use*. This lemma is the honest deliverable: it converts "E7 is hard"
into "E7 = (this trivial skeleton) ∘ (RvM local count) ∘ (partial-fractions error
bound)", isolating the wall.
