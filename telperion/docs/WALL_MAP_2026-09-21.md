### 10.1 The exchange rate

Every rung is a paired zero sum, and the pair term of a zero rho at rung N = n + 1 is
2 - 2 cosh(N log r) cos(N theta) with r e^{i theta} = rho/(rho - 1). Three facts price it:

* on the line r = 1 and the term is 2(1 - cos N theta) >= 0;
* |log r| <= |theta| <= 1/|Im rho| once |Im rho| >= 1;
* cosh a cos b <= 1 for |a| <= |b| <= pi/2, and cos b <= 0 on [pi/2, 3 pi/2].

So a zero with |Im rho| >= 2N/(3 pi) contributes a nonnegative term whether or not it is on the
line (LiLadderHeight.re_liPairedSummand_nonneg_of_height, RvMBridge28.pair_re_nonneg_of_far), and

    zeros on the line up to height T (T >= 1)  ==>  rung n >= 0 for every n + 1 <= 3 pi T / 2

(LiLadderHeight.li_rung_of_zeros_on_line_below; RvMBridge28.liLimit_re_nonneg_of_line_below in
the B7 vocabulary). The rate is sharp for the termwise method: at N theta = 2 pi k an off-line
term is 2 - 2 cosh a < 0. The literature's folklore rate is quadratic in T but asymptotic with no
explicit constant (LI_FACE_SURVEY section A1); this one is linear and explicit.

Numerics (research/li_face_numerics.md, N <= 2000, grids of 203 x 5000): no failure of the termwise
lemma above the proved threshold; the true threshold is gamma_min(N) = N/(2 pi) + 1/2 + o(1), all
