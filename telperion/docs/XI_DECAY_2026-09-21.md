## The argument

On the open half-plane Re s > 1 every hypothesis of `logDeriv_xi_eq` (E6Bridge18) and of
`Zeta23.WeilEF.logDeriv_completedZeta` holds (s ≠ 0, 1; ζ(s) ≠ 0 by
`riemannZeta_ne_zero_of_one_lt_re`; Λ(s) ≠ 0 because ζ = Λ / Γ_ℝ via `riemannZeta_def_of_ne_zero`),
and the two remaining logarithmic derivatives have closed forms there:
`Zeta23.RvM.logDeriv_Gammaℝ` (Γ_ℝ'/Γ_ℝ = -(log π)/2 + ψ(s/2)/2 on Re s > 0) and
`LSeries_vonMangoldt_eq_deriv_riemannZeta_div` (ζ'/ζ = -L(Λ) on Re s > 1). So

```
logDeriv xi s = s⁻¹ + (s-1)⁻¹ + (-(log π)/2 + (1/2) ψ(s/2)) - L(Λ)(s)      (logDeriv_xi_eq_of_one_lt_re)
```

holds on an open set, hence can be differentiated termwise at any real σ ≥ 2:

```lean
theorem deriv_logDeriv_xi_real {σ : ℝ} (hσ : 2 ≤ σ) :
    deriv (logDeriv xi) σ = -1/σ² - 1/(σ-1)² + (1/4) * deriv digamma (σ/2) + deriv (logDeriv riemannZeta) σ
theorem deriv_logDeriv_zeta_eq {s : ℂ} (hs : 1 < s.re) :
    deriv (logDeriv riemannZeta) s = LSeries (LSeries.logMul ↗Λ) s
```

(the ψ derivative through `analyticAt_digamma_of_re_pos`, the L-series derivative through Mathlib's
`LSeries_hasDerivAt` with `abscissaOfAbsConv ↗Λ ≤ 1`). Each of the four pieces tends to 0.

### The trigamma piece

Zeta23 provides `Stirling.hasSum_trigamma : HasSum (fun n => 1/(z+n)^2) (deriv digamma z)` only on
`Complex.integerComplement`, which misses the positive integers that the real ray σ/2 passes
through. `hasSum_trigamma_of_re_pos` extends it to all Re z > 1/2: at an integer z both sides are
continuous (the series side by `continuousOn_tsum` with the uniform majorant 1/(n+1/2)^2 on
Re w ≥ 1/2, the ψ' side because ψ is analytic on Re z > 0), and they agree on the punctured
neighbourhood ball(z, 1/2) \ {z}, which contains no integer; `tendsto_nhds_unique` on 𝓝[≠] z.

On the real ray the series is bounded by telescoping, 1/(x+n)^2 ≤ 1/(x+n-1/2) - 1/(x+n+1/2):

```lean
theorem norm_deriv_digamma_real_le {x : ℝ} (hx : 1 ≤ x) : ‖deriv digamma x‖ ≤ 1/(x - 1/2)
theorem digamma_deriv_tendsto_zero : Tendsto (fun σ : ℝ => deriv digamma (σ/2)) atTop (𝓝 0)
```

### The ζ'/ζ piece

L(log · Λ)(σ) = Σ_n log n · Λ(n) · n^{-σ}. Tannery (`tendsto_tsum_of_dominated_convergence`, as in
E6Bridge18 section D) against the σ = 2 terms: for σ ≥ 2 each term is dominated by its value at 2
(`norm_term_le_of_two_le`, via `LSeries.norm_term_eq` and `Real.rpow_le_rpow_of_exponent_le`), the
σ = 2 terms are summable in norm (`LSeriesSummable_logMul_of_lt_re` + `summable_norm_iff`), and each
term tends to 0 (n = 0, 1 are identically 0; n ≥ 2 by `tendsto_rpow_atTop_of_base_gt_one`).
