# Six uniformization axes for RH → certificate-shaped triage (deep research, 2026-09-09)

Synthesis of six adversarially-verified findings objects (Li's criterion; Jensen–Pólya/GORZ; Weil positivity; zero-free-region widening; Baez-Duarte/Nyman–Beurling; Hilbert–Pólya/de Branges), each `{finding, verdict}`, with every verifier ruling applied. `conjecture1_proved = False`; category discipline enforced throughout. This document ranks the six as **mathematics** and as **Telperion program directions**, never as proof paths.

## 1. Frame: the honesty theorem

Each axis supplies a *uniform object* `U` and a classical equivalence `RH ⟺ (U holds uniformly)` — positivity of every Keiper–Li coefficient, hyperbolicity of every Jensen polynomial, positivity of the Weil functional on the whole test space, a zero-free half-strip reaching `Re = 1/2`, vanishing of the Nyman–Beurling distance limit, or self-adjointness of a Hilbert–Pólya operator. In every case the equivalence itself is a *finite-face-plus-infinite-quantifier* structure: the repo can kernel-check the finite faces (individual rungs, the iff-scaffold, ξ-bridge, Gram-PSD instances), but the completion is an infinite conjunction / uniform-in-parameter statement whose discharge *is* RH. **The honesty theorem for a certificate-compilation engine is therefore: a complete uniform certificate exists iff RH is true.** No untrusted generator + trusted kernel can manufacture the uniform object without a proof of the uniform object, i.e. without RH. So each route's *completion IS the open problem*, and the ranking below is a ranking of partial-uniform traction and program-fit, not of proximity to a proof. None of the six closes RH.

## 2. Per-axis assessment

### 2.1 Li's criterion (Keiper–Li coefficients)

**Uniform object + attribution.** `λ_n = Σ_ρ [1 − (1−1/ρ)^n]` (sum over nontrivial zeros, conditionally convergent), equivalently `λ_n = (1/(n−1)!) dⁿ/dsⁿ[ s^{n−1} log ξ(s)]|_{s=1}`. **RH ⟺ λ_n > 0 for all n ≥ 1** — note the canonical statement is *strict* positivity (Li 1997, Wikipedia); the repo's non-strict `0 ≤ λ_n` finite face is defensible but should be flagged as a convention choice, not the literal literature statement. Keiper introduced the coefficients numerically (Math. Comp. 58, 1992); Li proved the equivalence (J. Number Theory 65, 1997); Bombieri–Lagarias (J. Number Theory 77, 1999) recast it as an instance of a universal positivity inequality for arbitrary complex multisets and derived it from Weil's criterion; Freitas (arXiv:math/0507368, 2005) generalized to a τ-family detecting zero-free half-planes.

**Finite face in the kernel.** `li_criterion_rh_iff`; rungs `li_rung_0..19` (finite prefix positivity); refutation atom `li_neg_refutes_rh`; `LiLadder.li_rh_iff_tail` (prefix-peeling to tail positivity); `RvMXiBridge` (`riemannXi = xiTele`). All finite, decidable.

**Gap character.** Circular-RH-equivalent, no known monotone/unconditional handle.

**Verified literature (2015–2026 + foundations).** Numerical positivity verified to `n ≤ 10⁵` (confirmed). Structural sharpenings: **Voros (Math. Phys. Anal. Geom. 9, 2006)** — the dichotomy RH-true ⟺ `λ_n` tempered `∼ ½ n log n`, RH-false ⟺ non-tempered oscillations; the tempered estimate is derived *under RH*. **Coffey (arXiv:math/0402168, math/0404213)** — exact split into an archimedean (provable) trend plus a prime-power/von-Mangoldt oscillation, with conditional asymptotic `λ_n ∼ n(A log n + B)`, `A>0`. **Freitas Cor. 4.2** — a single off-line zero forces *infinitely many* negative coefficients (verified from the PDF): the load-bearing "no finite/one-sided handle even to a weaker-than-RH region" fact.

**Notable attempts, honest status.** Voros/Coffey/Freitas/Bombieri–Lagarias: partial-results. **Refuted/contested proof-claims — softened per verifier:** Li's own arXiv:0807.0090 (2008) claimed proof was withdrawn "due to a mistake on pg. 29" (so the failed-attempt signal is fair *for that version*), but later revisions were resubmitted and a v10 is active as of Oct 2025 — the flat "withdrawn" label is stale; these later versions are not peer-accepted. The Agélas GRH claim *is* refuted by Brent (arXiv:2103.09418), **but** Brent ties the error to a Vassilev-Missana prime-zeta lemma, *not* to Li-coefficient positivity — so this is at most loosely connected to this axis and should not be cited as a Li-route failure. The retracted Cambridge Open Engage "New Criterion" (647ff4fe) is a **misattribution**: it uses the Solé–Planat Chebyshev-ψ criterion, a *different* RH-equivalence, and is **not** in the Li-coefficient family — drop it from this axis. Net: of the "circle of failed proofs," only Li's own 2008 attempt is squarely on this axis, so the "empirical signature of circularity" rhetoric should be trimmed; the circular classification does *not* depend on that empirical argument and stands.

**Telperion-fit + ceiling.** Sound core: kernel-verify `li_criterion_rh_iff` + `RvMXiBridge`; compile finite positivity rungs (extendable toward the `n ≤ 10⁵` frontier via interval arithmetic on `taylorCoeff`); carry `li_neg_refutes_rh` — the genuinely one-directional payload (a certified `λ_n < 0` validly refutes RH). Conditional-asymptotic implications can be hosted with the hypothesis flagged as undischarged. **Ceiling:** the open obligation is the infinite conjunction (= tail positivity = tempered growth without non-tempered oscillation). By Freitas Cor. 4.2 there is no finite positivity witness and no one-sided asymptotic handle; the missing uniform-in-n lower bound on the oscillation term does not exist unconditionally in the literature (it is RH). Certificate compilation cannot reach it.

### 2.2 Jensen–Pólya / GORZ hyperbolicity

**Uniform object + attribution.** Expand `(1/8)Ξ(x) = Σ_k γ(k) x^{2k}/(2k)!`; the Jensen polynomial is `J^{d,n}_γ(X) = Σ_{j=0}^d C(d,j) γ(n+j) Xʲ`. **RH ⟺ every `J^{d,n}` is hyperbolic (real-rooted) for all `d ≥ 1` and all `n ≥ 0`** — equivalently Ξ ∈ Laguerre–Pólya class. This is Pólya's 1927 theorem (recasting Jensen's criterion); the modern normalization / higher-order-Turán link is Csordas–Norfolk–Varga (Trans. AMS 296, 1986) and Csordas–Varga (Adv. Appl. Math. 11, 1990). The doubly-uniform object (all d AND all n) is exactly RH.

**Finite face in the kernel.** `jensen_box_hyperbolic_deg2_{0,1,2}` + `hyperbolic_deg2_of_discrim_nonneg` (degree-2 hyperbolicity at shifts `n=0,1,2` via discriminant `≥ 0`); `JENSEN_HYPERBOLICITY_STATUS` names the uniform-in-degree threshold `N(d)=n₀(d)` as the RH-closing out-of-scope piece. (A working-tree grep did not locate these identifiers — consistent with an unmerged branch; assessment proceeds from the stated repo state.)

**Gap character.** Reduces-to-named-subproblem: uniform control of `n₀(d)` across all `d`.

**Verified literature (this axis has the most genuine unconditional partial-uniform traction).** Pre-2019: hyperbolic for all `n` up to `d ≤ 3` — GORZ credit this range *jointly* to Csordas et al. and Dimitrov–Lucas, so the clean "d≤2 via CNV / d=3 via Dimitrov–Lucas" split is the *commonly identified* attribution, not a verbatim-sourced fact (soften accordingly). **GORZ (PNAS 116, 2019; arXiv:1902.07321)** — Hermite-limit theorem: for each fixed `d`, `J^{d,n}` is hyperbolic for all *sufficiently large* `n`, with **ineffective** `n₀(d)`; plus all-`n` unconditional for `1 ≤ d ≤ 8` (Thm 2). Both confirmed from the PNAS full text. **GORTTW (Adv. Math. 397, 2022; arXiv:1910.01227)** — effectivize via low-lying zeros of `Ξ^{(n)}`: **all-`n` hyperbolic for `d ≤ 9×10²⁴`** (confirmed verbatim). **O'Sullivan (arXiv:2007.13582, 2020)** — an *effective* threshold `n₀(d)`; the specific "exponential `~ c·eᵈ`" form is **could-not-verify** (abstract non-specific, PDF unrendered) and the journal is *Research in the Mathematical Sciences* (2021), **not** "Res. Number Theory" — hedge the exponential claim and fix the cite. **Larson–Wagner (Res. L-function extension: arXiv:1905.11269.

**Gap (precise).** Quantifiers run opposite: GORZ/O'Sullivan give, for fixed `d`, an `n₀(d)` beyond which all `n` are fine; GORTTW closes all `n` for the fixed window `d ≤ 9×10²⁴`. RH needs all `d` with all `n`, i.e. a `d`-uniform control of `n₀(d)` collapsing the `d→∞` family to a finite check — of which no known (exponential/super-exponential) form is small enough.

**Telperion-fit + ceiling.** The most certificate-friendly axis at the rung level: each atomic obligation "the explicit real polynomial `J^{d,n}` is hyperbolic" is decidable by a discriminant/Sturm/Hermite-PSD-Hankel certificate — the same box-positivity/SOS-Handelman cone the memory shares with the BG endgame. The engine can extend the deg-2/n≤2 boxes to arbitrarily many `(d,n)`, reproduce the `d≤8` GORZ range, spot-check inside the `d ≤ 9×10²⁴` window, and discharge the finitely-many small-`n` cases once an `n₀(d)` bound is in hand. **Ceiling:** it cannot supply the ineffective→effective control of `n₀(d)` GORZ leaves open, nor bound `n₀(d)` uniformly in `d`; the known thresholds grow with `d` and the degrees are infinite (an unbounded certificate stream, not a finite compilation). The uniform Hermite-limit estimate is genuine analytic number theory (central-derivative asymptotics / zero-density input), not a finite predicate. The ladder is infinitely tall.

### 2.3 Weil positivity / explicit formula

### 2.4 Zero-free-region widening toward `Re = 1/2`

**Uniform object + attribution.** A zero-free half-strip reaching the critical line: `ζ(σ+it) ≠ 0` for all `σ > 1/2`. This is **not** a third-party equivalence — it is a **tautology**: pushing the region to any fixed line `Re = c ≤ 1/2` *is* RH (Riemann 1859). Graded objects short of it: the de la Vallée-Poussin region `1−β ≤ c/log|t|` (1899); Vinogradov–Korobov `1−β ≤ c/((log|t|)^{2/3}(loglog|t|)^{1/3})` (1958); and, weaker than RH but *completely open*, the Quasi-RH (any fixed `δ>0` strip `σ > 1−δ`).

**Finite face in the kernel.** `riemannZeta_ne_zero_region` (effective dVP region, rate `dlvpRateC`); `ZeroFreePolylog` (`Re s > 1 − c/(γ⁴(1+log 2γ))`, PR #185/#188, kernel-clean — memory adds the honest caveat that the dominant `γ⁴` factor is Borel–Carathéodory-gated and the result is explicitly *not* a proof of RH); `RHInBoxBands`. Real and unconditional but at the weakest (dVP-1899 log-width) end of the ladder.

**Gap character.** Circular-RH-equivalent, no known handle.

**Verified literature.** dVP 1899 via the 3-4-1 inequality `3+4cosθ+cos2θ ≥ 0` fed through Borel–Carathéodory/Landau; the `log|t|` *form* never improved classically. Vinogradov & Korobov 1958: the sole *shape* improvement, still not to a fixed strip. Explicit-constant era (the live 2015–2026 work): Ford 2002; **Mossinghoff–Trudgian–Yang (arXiv:2212.06867, Res. Number Theory 2024)** — reigning explicit records `σ ≥ 1 − 1/(5.558691 log|t|)` (`|t|≥2`) and Vinogradov–Korobov constant `55.241` (`|t|≥3`), both verified verbatim; Yang et al. (2301.03165, 2306.10680); Heath-Brown-inspired 2603.21490. **Quasi-RH open** — no `δ>0` known after 125 years (confirmed). **Guth–Maynard (arXiv:2405.20552, Annals 2026)** — a *distinct* zero-*density* axis (first improvement on Ingham 1940 for `1/2 ≤ σ ≤ 3/4`); does not widen the region toward `1/2`.

**Notable attempts, honest status.** dVP, VK, Ford, MTY, Guth–Maynard: partial-results; Quasi-RH: open; elementary "simple proofs" (arXiv:2209.01890): contested. **Softened per verifier — the one genuine overstatement:** that even the Lindelöf Hypothesis `μ(1/2)=0` does not imply RH is a true theorem (RH ⇒ Lindelöf is one-way), *but* the finding's claim that the growth-bound → zero-repulsion mechanism is "**provably** incapable" / a "decisive no-go" is a **heuristic barrier**, not an impossibility theorem (Lindelöf bounds the critical line; zero-free-region methods use bounds near `σ=1`; no theorem forbids every growth-bound argument from reaching a fixed strip). Relabel "provably capped" → "strongly suggests / heuristic barrier / no known route." This softening does **not** weaken the ceiling below, which rests on finiteness-vs-uniformity.

**Telperion-fit + ceiling.** Genuinely well-suited to the explicit-constant frontier: mechanically verify the MTY-style constants (they rest on trigonometric-polynomial nonnegativity generalizing 3-4-1, explicit `|ζ|` bounds, Vinogradov-integral estimates — all finite positivity certificates feeding the shared box-positivity engine), gate the effective dVP region and its polylog sharpening, and produce `RHInBoxBands`-style finite-height no-zero certificates (independent numerical RH is at `T ~ 10¹³`; a kernel-checked finite-band cert is a real artifact). **Ceiling:** the region is a curvilinear `f(|t|)`-family pinching to width 0 as `|t|→∞`; no finite composition of rungs, and no reachable limit of rungs, crosses from `c/log|t|` width to a fixed strip, let alone to `1/2`. Pursue as evidence-and-tooling, never as closure.

### 2.5 Baez-Duarte / Nyman–Beurling

**Uniform object + attribution.** In `H = L²((0,∞), t^{-2q}dt)`, let `d_N` = distance from the target (`χ_{(0,1)}`, or the constant 1 on `(0,1)`) to the span of the first `N` dilations of the fractional part. **RH ⟺ d_N → 0.** Chain: **Nyman (1950 thesis) → Beurling (PNAS 41:312–314, 1955, real dilations) → Baez-Duarte (2003, integer dilations, `d_N → 0` form)**. *Correct the venue per verifier:* the Baez-Duarte strengthening appeared in **Atti/Rendiconti Lincei Mat. Appl. 14 (2003) 5–11** (arXiv:math/0202141), **not** Advances in Mathematics. Balazard–Saias–Yor (Adv. Math. 143, 1999) gave the `log|ζ|` integral form.

**Finite face in the kernel.** For fixed `N`, `d_N² = min_a [C − 2 Σ a_n F_n + Σ a_m a_n G_{m,n}]` = a Gram-determinant ratio `det(G_{N+1})/det(G_N)`; entries `G_{m,n}` are closed-form Vasyunin cotangent sums `V(m,n) = Σ_{k=1}^{m-1} {kn/m} cot(πk/m)` plus elementary log/Γ terms. Matches the `RHLinalg` Gram prelude + uniform-memo §3. Fully kernel-checkable per `N`; the `N→∞` limit is not a finite face.

**Gap character.** Circular-RH-equivalent, no known handle.

**Verified literature.** **PARTIAL-UNIFORM lives here as rate bounds.** Baez-Duarte–Balazard–Landreau–Saias (Adv. Math. 149, 2000): unconditional lower bound `d_N` cannot beat `1/√(log N)`. **Burnol (Adv. Math. 170:56–70, 2002; math/0103058):** the strongest unconditional statement, `liminf (log N) d_N² ≥ Σ_ρ m(ρ)²/|ρ|²` — non-vacuous but a *lower* bound. **Bettin–Conrey–Farmer (Proc. Steklov 280, 2013; arXiv:1211.5191):** matching upper bound `c/log N` via `V_N = Σ μ(n)(1 − log n/log N) n^{-s}` — but **only conditionally** (assuming RH *and* `Σ 1/|ζ'(ρ)|² ≪ T^{3/2−δ}`; the conditionality verified verbatim). Conjectured exact asymptotic `d_N² ∼ (1/log N) Σ_{Re ρ=1/2} m(ρ)²/|ρ|²` — *soften per verifier:* the `m(ρ)²`-vs-`m(ρ)` distinction collapses only under simple zeros, and the RH-value "≈ 0.0461" `= (2+γ−log 4π)/log N` is author-computed (≈ 0.0462), not a cited constant. de Roton (TAMS 2007) extended criterion + lower bound to the Selberg class (venue could-not-verify; result confirmed). Bettin–Conrey (arXiv:1111.0931) — Vasyunin reciprocity. Ehm (arXiv:2405.06349, 2024) — explicit Gram entries; the specific closed form and `G_{1,1}=log 2π − γ ≈ 1.2607` are **could-not-verify** (paper exists; formulas not extracted). Darses–Hillion (Confluentes Math. 2019): probabilistic generalizations, open.

**Telperion-fit + ceiling.** Certificate-shaped and matching the Gram prelude: per `N`, an emitter can generate `G_N` from exact Vasyunin sums + log/Γ enclosures (reusing `transcendental_enclosure`), emit a kernel-checkable PSD certificate (Cholesky/LDLᵀ over exact rationals + certified transcendental constants), certify `d_N²`, and certify the monotone decrease `d_{N+1}² ≤ d_N²` (adding a basis vector cannot increase the projection distance). No Lean formalization of the Baez-Duarte Gram/Vasyunin machinery is known to exist (plausible; treated as could-not-verify), so this is real, novel-to-formalize content composing with the box-positivity engine. **Ceiling:** Burnol's *unconditional positive lower bound* makes every finite `d_N` strictly positive **regardless of RH's truth** — so no finite certificate distinguishes RH-true from RH-false. Closure needs a uniform effective upper bound `d_N² ≤ C/log N` for all `N` with the right constant, which (Bettin–Conrey–Farmer) requires controlling `Σ 1/|ζ'(ρ)|²` over all zeros — an open transcendental input the kernel cannot manufacture. This axis is *cleaner to formalize per-N* than Li/Weil (one Gram matrix, closed entries) but arguably *harder to leverage toward closure*, precisely because Burnol makes finite certificates manifestly non-decisive (whereas one failed Li coefficient would at least be a finite refutation).

### 2.6 Hilbert–Pólya / de Branges (spectral realization)

**Uniform object + attribution.** Three related RH-equivalent targets: (1) **Hilbert–Pólya** — a self-adjoint `H` with spectrum `{γ}` so zeros are eigenvalues of `1/2 + iH`; folklore, *softened per verifier:* not "no written record survives" but **no contemporaneous (1910s) written record** — the idea is documented only via Pólya's much-later Jan 3, 1982 letter to Odlyzko; it entered the literature via Montgomery (1973) pair-correlation + Odlyzko GUE numerics. (2) **Weil positivity** — the genuine iff (§2.3-adjacent). (3) **de Branges** — a *sufficiency* (positivity conditions on an `H(E)` space ⟹ GRH), not an equivalence.

**Finite face in the kernel.** **None.** The 2015–2026 triage found no concrete finite PSD certificate on this lane; `RH_F1_HODGE_INDEX_FRONTIER`, `RH_F1_SURFACE_BLUEPRINT`, `RH_L2_CONSTRUCTION_MANUAL` sketch spectral/index-theoretic analogies but are not kernel-checkable finite objects.

**Gap character.** Circular-RH-equivalent, no known handle.

**Verified literature.** Weil 1952 (iff). **Berry–Keating (SIAM Review 41:236, 1999)** `H=xp` — semiclassical, recovers only the *average* counting function; no exact self-adjoint operator. **Sierra–Townsend (PRL 106:200201, 2011)** — closed orbits, still only average zeros. **Connes (Selecta Math 5, 1999)** — zeros as absorption spectrum; reduces RH to (unproven) trace/Weil positivity. **Connes–Consani–Moscovici** prolate/scaling program (Annals Funct. **Telperion-fit + ceiling.** **LOW — the least certificate-fit lane, and it says so.** The RH-equivalent target (Weil positivity on an infinite test space, or self-adjointness of an unbounded operator) is intrinsically infinite-dimensional and analytic, not a finite face. Honest slivers: (a) formalize the equivalence lemmas (Weil positivity ⟹ RH; self-adjoint-with-spectrum-`{γ}` ⟹ RH) as trusted scaffolding — *not* progress toward RH; (b) certify finite-truncation Weil-form Gram/moment PSD via interval arithmetic (overlapping §2.3-W1, cf. arXiv:2605.20224); (c) certify first-`N`-zero eigenvalue enclosures (e.g. prolate operator) as finite facts. **Ceiling:** none of these close the finite→infinite positivity/self-adjointness gap; a finite kernel cannot certify infinite-dimensional positive-definiteness or unbounded-operator self-adjointness.

## 3. Cross-cutting: the same wall in six coordinate systems

The six axes are one obstruction re-coordinatized. RH is a single "all off-critical zeros are forbidden" statement, and each axis re-expresses "for all zeros" as an infinite quantifier over a *different* index set:

- **Li** — *height-universality*: positivity of `λ_n` for all `n`; the oscillation term (Coffey/Voros) is the full zero sum, so "all `n`" = "all zeros."
- **Jensen–Pólya** — *degree-exhaustion*: hyperbolicity for all `d` (with all `n`); the doubly-uniform quantifier over degree.
- **Weil** — *cone-exhaustion*: positivity of `W` on all admissible `f`, i.e. over the whole (infinite-dimensional) test-function cone / all windows `L`.
- **Zero-free region** — *height-universality again*, tautologically: the curvilinear region must hold uniformly for all `t` and pinch to a fixed line.
- **Baez-Duarte** — *basis-exhaustion*: the projection error over all `N` dilations must vanish in the `N→∞` limit.
- **Hilbert–Pólya/de Branges** — *spectral-realization*: a single operator whose spectrum is *all* the zeros simultaneously (self-adjointness = the uniform statement).

In each system the finite faces are genuinely finite and kernel-checkable — a rung `n`, a box `(d,n)`, a window `L`, a Gram size `N`, a height band `T`, a truncation. What is *never* finite is the passage to the uniform object, and crucially the partial results confirm the wall is real *inside* each coordinate system: Freitas Cor. 4.2 (a single off-line zero ⟹ infinitely many negative `λ_n`), GORZ's ineffective `n₀(d)` with `d→∞` thresholds worsening (O'Sullivan/Larson-Wagner), Groskin's `log(T)/T` tail budget and Zhu's doubly-exponential `2πe^{4e^L}` window resolution, Burnol's unconditional positive `d_N` lower bound, and the absence of any uniform-in-`N` self-adjoint realization. Changing coordinates changes *what the infinite quantifier ranges over* — never its cardinality. A certificate-compilation engine lives in the finite faces of every coordinate system and is bounded, in all six, by the same fact: the uniform object's discharge is RH.

## 4. Two-axis ranking

**(i) Mathematical promise — genuine unconditional partial-uniform traction vs. circularity.**

1. **Jensen–Pólya/GORZ** — clearly first. The *only* axis with unconditional partial-uniform theorems that advance in the RH direction: all-`n` hyperbolicity for `d ≤ 9×10²⁴` (GORTTW), the fully-understood fixed-`d`-large-`n` regime (GORZ Hermite limit), clean `d ≤ 3` Turán proofs. The gap (`d`-uniform `n₀(d)`) is sharply named, not circular.
2. **Weil positivity** — second. A clean iff whose *finite-dimensional structure is tame* (2026 finite-reduction theorems), with real partial-uniform gains (Bombieri–Yoshida small-support, Connes–Consani archimedean-place positivity), but the uniform quantifier and the irreducible tail keep it circular at the top.
3. **Baez-Duarte** — third. Genuine unconditional rate theorems (Burnol lower bound; conditional matching upper bound), cleanest per-`N` object, but Burnol's positive lower bound makes finite stages provably non-decisive — traction is *measurement*, not narrowing.
4. **Li's criterion** — fourth. A clean equivalence with a sharp *dichotomy* (Voros) and exact arithmetic split (Coffey), but no unconditional uniform-in-`n` handle; Freitas forecloses even a weaker-than-RH region. Maximally circular.
5. **Zero-free-region widening** — fifth. Least promising as closure and honestly tautological (reaching `1/2` *is* RH); Quasi-RH itself open for 125 years; the FORM improved once (1958). All live progress is explicit-constant refinement or the distinct density axis.
6. **Hilbert–Pólya/de Branges** — sixth. No finite face, de Branges sufficiency refuted-for-zeta (Conrey–Li), the physical Hamiltonians semiclassical/contested/refuted; the healthiest program (Connes–Consani–Moscovici) is conceptual + numerical, no proof.

**(ii) Telperion program-fit — highest-value place to point finite kernel-checked certificate work.**

1. **Jensen–Pólya/GORZ** — highest-value. Every rung is a decidable hyperbolicity certificate (discriminant/Sturm/PSD-Hankel) the kernel can check; the repo's deg-2 boxes are a faithful seed; it directly reuses the shared box-positivity/SOS-Handelman engine.
2. **Weil positivity** — a very close second and arguably the *most shovel-ready* because the 2026 literature (Groskin, Zhu) has already reduced finite windows to single-matrix PSD in closed form, and the repo already owns both halves (`rect_explicit_formula` + `RHLinalg`). W1 is a concrete, publishable next deliverable, plus a verified Groskin-style two-sided certification calculus and a Sylvester-inertia RH-violation bridge.
3. **Baez-Duarte** — strong third; per-`N` Gram-PSD + monotone tower, novel-to-formalize, reuses `transcendental_enclosure`.
4. **Zero-free-region** — valuable as *tooling* (verified explicit constants, finite-height bands), not closure.
5. **Li** — bounded showcase (iff + ξ-bridge + finite rungs + the sound refutation atom).
6. **Hilbert–Pólya** — lowest fit; only equivalence-lemma scaffolding and finite-truncation shadows.

**Where a genuine attempt would begin (top-ranked axis, Jensen–Pólya).** Build a `jensen_hyperbolic` emitter that, given `(d,n)`, assembles `J^{d,n}` from certified enclosures of the Ξ Taylor coefficients `γ(k)` at `1/2` and emits a kernel-checkable real-rootedness certificate — the PSD-ness of the Hermite/Hankel quadratic form (Gram decomposition over exact rationals plus certified transcendental entries), or a Sturm-chain sign certificate. First target: mechanically reproduce the GORZ `d ≤ 8` all-small-`n` range and spot-check chosen `n` inside the `d ≤ 9×10²⁴` GORTTW window, then discharge the finitely-many small-`n` obligations *conditional on* an imported `n₀(d)` bound (flagged as an undischarged analytic input, never as progress toward RH). This is the same box-positivity cone as the BG endgame, so the emitter composes with existing machinery.

**Honest ceiling, stated for all six.** None of these axes closes RH. Each route's completion — the doubly-uniform `n₀(d)` control (Jensen), positivity on the full window family (Weil), tail positivity (Li), a fixed zero-free strip (region), the `N→∞` limit (Baez-Duarte), a self-adjoint realization (Hilbert–Pólya) — *is itself the open problem*. A certificate-compilation engine compiles arbitrarily many finite rungs and a verified certification calculus on top of them; it cannot manufacture the uniform object, because the uniform object is RH. **`conjecture1_proved = False`.**
