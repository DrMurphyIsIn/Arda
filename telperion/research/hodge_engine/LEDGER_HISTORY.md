- R15 WIDER-THAN-LINE POSITIVITY IS BLIND. A mechanism must use something that sees the discreteness or line-confinement of zeros without reading them out (reconcile with R1).
- R16 SPLIT FAMILIES NEED UNBOUNDED COMPLEXITY. If 0 <= M_p <= Q, then dist_{Q^{-1}}(W_p v, span{V_i v})^2 <= v^T Q v. A d-dimensional linear split family is feasible at x only if it approximates the near-null data to within sqrt(lambda(x)). Any proposed split must state its complexity as a function of x and show that the approximation error beats sqrt(lambda(x)) uniformly. Otherwise it dies by B26.
