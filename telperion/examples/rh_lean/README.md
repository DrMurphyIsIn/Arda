# The RH kernel-gated library — index and honest scope

Every module here is generated by a Telperion emitter (generator UNTRUSTED) and **kernel-checked by
Lean 4 / Mathlib v4.32.0** through the `telperion-rh-lean` CI gate — the Lean kernel is the sole arbiter.
As of this writing: **111 theorems across 25 modules, all green.**

> **The one load-bearing fact.** None of this proves, or approaches proving, the Riemann Hypothesis.
> RH is an *infinite* condition (all zeros / all n / all degrees) with no known finite or inductive
> structure a certificate can close — that is the essence of its difficulty, not a limitation of the
> tooling. Everything below is a *finite* verification, a *reduction*, an *equivalent reformulation*, or
> *infrastructure*. `conjecture1_proved = False`, everywhere, always. Genuine RH progress lives in deep
> analysis (zero-free-region widening, zero-density, critical-line proportion, de Bruijn–Newman Λ) — none
> of it certificate-reachable.

## RH-adjacent modules

### Hyperbolicity ladder (Laguerre–Pólya / Jensen) — RH-NECESSARY, finite shifts, enclosure-conditional
- `Turan`, `Jensen`, `Newton`, `Toeplitz` — degree-2/3 Jensen hyperbolicity + Newton & Pólya-frequency
  (Toeplitz-minor) inequalities for the ξ coefficients.
- `QuarticJensen` (d=4), `HankelJensen` (**d=5, uniform Hermite/Hankel-minor emitter** — any-degree
  criterion via `WorstCorner`, subsuming turan/cubic/quartic). See memory for the GORZ finite-residual
  **no-go** (d≤8 already human-proven; d≥9 worst-corner-infeasible).

### Robin's criterion — RH-EQUIVALENT, arithmetic, finite/reduction
- `Robin` — `σ(n) < e^γ·n·log log n` for comfortable n **and all 13 RH-tight superabundant numbers in
  (5040, 2×10⁶]** (tight `eulerMascheroniSeq` γ + `taylor_log` loglog). Unconditional.
- `RobinReduction` — `robin_G_monotone` (least Robin counterexample is superabundant, Akbary–Friggstad core).
- `NicolasBridge` — `φ(n)·σ(n) < n²` (Nicolas⇒Robin connector) at primorials.
- Scope docs: `ROBIN_RH_MAP.md` (D1, 46 sourced theorems + the Wall), `ROBIN_FORMALIZATION_TRIAGE.md` (D2),
  `ROBIN_REDUCTION_D3.md` (D3 scope), `ROBIN_HONESTY_AUDIT_D5.md` (D5 audit).

### The analytic frontier — where certificates genuinely touch the RH-progress line
- `TrigNonneg` — general **nonnegative cosine-polynomial** emitter (Markov–Lukács manifest factorization).
  Mertens `3+4cos+cos2 = 2(1+cos)²` is the seed of the classical **zero-free region**; better polynomials
  give better constants. *A certificate feeding the region — the region itself needs the (unformalized,
  research-scale) ζ growth bound.* See `ZETA_FOUNDATION_SCOPE.md`.
- `ZeroFreeBridge` — **the certificate meets ζ.** Six kernel-verified theorems proving the Mertens
  inequality actually holds on the Dirichlet series of `−ζ′/ζ`: for σ>1,
  **`0 ≤ 3·Re L(σ) + 4·Re L(σ+it) + Re L(σ+2it)`** where `L = LSeries(Λ) = −ζ′/ζ`. The crux `cpow_re`
  (`Re(n^{−s}) = n^{−σ}cos(t·log n)`) → `term_re` → per-`n` positivity → summed via
  `LSeriesSummable_vonMangoldt` + `Complex.re_tsum` + `tsum_nonneg`. The final theorem
  `zeta_logDeriv_comb_nonneg` restates it **literally about ζ's log-derivative** —
  `0 ≤ 3·Re(−ζ′/ζ)(σ) + 4·Re(−ζ′/ζ)(σ+it) + Re(−ζ′/ζ)(σ+2it)` — via Mathlib's
  `LSeries_vonMangoldt_eq_deriv_riemannZeta_div`. This is the *exact positivity* the classical de la
  Vallée Poussin zero-free-region argument runs on — the `vonMangoldt` machinery that
  `ZETA_FOUNDATION_SCOPE.md` had listed as missing. *Still NOT a proof of RH:* the region also needs
  the log-derivative→product step and the ζ growth bound (both unformalized, research-scale). The
  positivity heart is done; what remains is classical complex analysis, not certificate-shaped.
- `WeilPositivity` — **the PSD certifier pointed at the Weil form** (Sylvester leading minors via
  `WorstCorner`). RH ⟺ Weil's quadratic functional is PSD; the finite Weil Gram matrix (entries from the
  explicit formula, validated vs the actual zeros to 26 digits) is certified positive-definite.
  RH-*equivalent*, necessary-not-sufficient — the natural home for our PSD/SOS technology, reusing the
  Hankel machinery on a new target. See `WEIL_POSITIVITY.md`.

### ζ / transcendental infrastructure
- `ZetaNumerics`, `ZetaEmitter` — two-sided `ζ(k)` bounds for k≥2 (incl. the Apéry `9/8 ≤ ζ(3) < 5/4`),
  Dirichlet-series + telescoping. `ExpBracket`, `LogBound`, `SqrtBracket`, `PiBracket`, `GammaHalf` —
  reusable rigorous rational brackets for exp / log / √ / π / Γ(1/2). Scope: `DEEP_TRANSCENDENTALS.md`,
  `ZETA_GAMMA_CONTRIBUTION.md`.

## How to trust it
`lake build` in `examples/rh_lean/` (or the `telperion-rh-lean` gate) kernel-checks every module. The
emitters live in `../../src/telperion/`; the library is regenerated by `build.py` (drift-checkable via
`build.py --check`). A defective certificate manifests as a compile failure, never a false theorem.
