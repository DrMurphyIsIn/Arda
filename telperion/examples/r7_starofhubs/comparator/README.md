# Comparator pilot — sharded (multi-file) emit

The star-of-hubs discharge is 972 theorems emitted across **9 shards**
(`Cells.lean`, `Cells2.lean`, … `Cells9.lean`; `ShardSpec.module_base =
R7Hyps.StarOfHubs.Cells`). This directory shows the Comparator bridge over a
sharded emit, generated by:

```sh
python3 examples/r7_starofhubs/generate.py --comparator
```

## One challenge per shard

Unlike a single-file emit, a sharded solution spans several Lean **modules**:
shard 1 is `R7Hyps.StarOfHubs.Cells`, shard *i* is `…Cells{i}` (exactly what
shard *i*+1 imports). Each shard **declares** its own 120 theorems, so the
bridge makes each shard its own `solution_module` with a paired challenge:

| file | role |
|---|---|
| `Cells{i}.comparator.json` | Comparator config: `solution_module` = `R7Hyps.StarOfHubs.Cells{i}`, `challenge_module` = `…Cells{i}Challenge`, `theorem_names` = that shard's theorems only |
| `Cells{i}Challenge.lean` | independent statement authority: that shard's signatures, proved by `positivity` (not Telperion's `field_simp; ring; rw` certificate), standalone (no import of the solution shards) |

The 9 configs partition all 972 theorems disjointly. Making each shard its own
`solution_module` — rather than one umbrella config — keeps **every** listed
theorem genuinely *declared* in the module Comparator loads, which is the robust
choice if Comparator reads "identical declarations" strictly. The configs are
independent, so CI can run them in parallel.

> The file names here are flat (`Cells3.lean`, `Cells3Challenge.lean`); in a real
> Lean project both live at their namespaced path (`R7Hyps/StarOfHubs/Cells3.lean`)
> so the module name resolves. Same as the solution shards in `../frozen/`.

## Running

Same prerequisites and lakefile as `../../bernoulli/comparator/README.md`. Build
the shard modules and their challenge modules, then run one config per shard:

```sh
for c in Cells*.comparator.json; do lake exe comparator "$c"; done
```

## Bridge API used

`telperion.comparator` exposes the sharded helpers:

```python
from telperion import sharded_challenge_configs, render_sharded_challenge_scaffolds, write_challenge_config

configs = sharded_challenge_configs(res, profile, module_base="R7Hyps.StarOfHubs.Cells")
for cfg in configs:
    stem = cfg["solution_module"].rsplit(".", 1)[-1]
    write_challenge_config(out / f"{stem}.comparator.json", cfg)
for chal_file, text in render_sharded_challenge_scaffolds(res, profile, module_base="R7Hyps.StarOfHubs.Cells").items():
    (out / chal_file).write_text(text)
```
